# GMDH Streamflow Modelling

Polynomial-network approaches to monthly and seasonal streamflow estimation and spatial sensitivity analysis.

## Methods
- Group Method of Data Handling (GMDH)
- Analysis of hydrological and climatic predictor variables
- Spatially differentiated sensitivity assessment
- Statistical evaluation of model performance

## Source files
- `src/gmdh_cluster_sensitivity.py`: catchment-group sensitivity analysis
- `src/tiff_line_cleanup.py`: figure export processing

## Data
Time-series observations and geospatial predictor datasets are managed independently of the source repository.
